# 限行 / 出行查询 Skill

## 目标

帮助用户确认某城市当前的机动车限行规则，判断自己是否受限、何时受限。

## 输入约定

从用户输入中抽取：
- **城市**：限行政策按城市不同（见 `knowledge/city-alias.md`，用 read_skill_file 读取）。
- **日期**：「今天 / 明天 / 某日」。默认 = 今天。
- **车牌尾号**：用户可能提供自己的尾号来问「我限不限」，需单独判断。

## 工作流（SOP）

1. **补全参数**：城市缺失则询问；日期缺失则默认今天。
2. **归一化城市**：查 `knowledge/city-alias.md`（用 read_skill_file 读取）。
3. **先查本地**：调用 `get_traffic` 拿本地规则表（北京/深圳/成都等，快路径）。
4. **本地没有就联网找**（关键）：若 get_traffic 返回「未收录」，**不要就此告诉用户查不到**，
   立即 `web_search`「{城市} 限行 最新规定」，再用 `fetch_url` 打开 1-2 个最权威的页面
   （优先当地交警 / 政府官网，其次本地宝、限行查询站），核实：是否限行、时段、区域、外地车规则、
   尾号轮换方式。多个来源冲突时以官方为准，并说明分歧。
5. **组织回答**，固定顺序：
   - 一句话结论：今天/明天该市是否限行（含「已暂停/未实施常态化限行」这类情况）。
   - 限行时段 + 限行范围（如环路、区域、是否只限货车）。
   - 外地车 / 本地车差异；若用户提供了尾号：直接判断「您的尾号 X 今日是否受限」。
6. **标注来源与时效**：给出信息来源（网站名 + 链接）与检索日期，末尾加「请以当地交管最新公告为准」。

## 约束规则

- 限行规则因城市、日期（含节假日豁免）不同，禁止套用通用规则，必须按城市核实。
- **本地规则表没有 ≠ 不知道**：必须走第 4 步联网检索把答案找出来；只有联网后仍无可靠信息，
  才如实说明「暂时查不到」并建议看当地交警最新公告。
- 不同城市差异极大：有的只限货车、有的只限外地车、有的已暂停常态化限行。不要把「没查到尾号轮换」
  直接推断成「全天不限行」，也不要把「限货车」说成「限所有车」。
- 禁止编造限行尾号、时段、区域；查到的信息必须能对应到具体来源链接。
- 涉及节假日是否豁免限行，需单独核实（部分城市节假日不限行）。

## Few-Shot 示例

**用户**：「今天深圳限行吗」
**回答**：
> 深圳对外地车牌在工作日早晚高峰（7:00-9:00、17:30-19:30）实施限行，本地粤 B 车牌不限行。今日为工作日，外地车牌上述时段受限。请以深圳交警最新公告为准。

**用户**：「东莞今天限行吗」（本地表未收录的城市——走联网兜底）
**回答**：
> 东莞目前没有实施常态化尾号限行，日常通行不限尾号；但部分区域对货车有管制（如立沙岛全天限制货车、大城区部分道路 7:00-9:00 与 16:00-20:00 限货车）。外地车在东莞不受尾号限行。
> 来源：无敌电动网《东莞限行限号最新规定》(m.modiauto.com.cn/cx/xh441900.html)、东莞本地宝限行专题（2026-11-14 检索）。政策可能调整，请以东莞交警最新公告为准。

**用户**：「我尾号 5，明天成都限不限」
**回答**：
> 成都按尾号轮换限行，明天限行尾号为 X 和 Y（以当周公告为准）。您的尾号 5 明天是否受限，需以成都交管当日公告确认。
