# 周报模板（read_skill_file 按需读取）

## 简洁版（默认）

```markdown
## 本周工作周报（MM.DD - MM.DD）

**本周完成**
- （动词开头 + 结果，每条一行）

**进行中**
- （事项 + 当前进度/卡点）

**下周计划**
- （事项 + 预期产出）

**风险与求助**
- （事项 + 需要的支持；没有则写「无」）
```

## 详细版

在简洁版基础上：
- 「本周完成」每条补充一行**背景/价值**说明（为什么要做这件事）；
- 「进行中」补充**预计完成时间**；
- 末尾加一段 100 字以内的**本周小结**（一句话主线 + 一句感受/复盘）。

## 语气指南

- 给领导：凝练、结果导向，少用形容词；
- 给团队：信息透明，进度和卡点写清楚，方便协作；
- 自己存档：可以口语一些，重点记教训和下一步。
