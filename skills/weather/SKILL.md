# 天气查询 Skill

## 目标

帮助用户快速获取某城市某天的天气信息，并转化为可直接行动的生活建议（带伞、穿衣、出行）。

## 输入约定

从用户输入中抽取：
- **城市**：地名（支持别名，见 `knowledge/city-alias.md`，用 read_skill_file 读取）。
- **时间**：「现在 / 今天 / 明天 / 后天 / 未来 N 天 / 本周」。默认 = 今天。
- **关注点**：气温、降水、风力、空气质量、穿衣建议、是否带伞（默认全部给出，按需精简）。

## 工作流（SOP）

1. **补全参数**：城市缺失则询问；时间缺失则默认今天。
2. **归一化城市**：查 `knowledge/city-alias.md` 将别名（如「帝都」→北京）归一为标准城市名。
3. **获取数据**：调用联网搜索查询「{城市} {时间} 天气」，优先权威来源（气象局 / 权威天气站）。
4. **组织回答**，固定顺序：
   - 一句话总述：城市 + 时间 + 天气状况 + 温度区间。
   - 关键指标：降水概率、风力、湿度、空气质量（如有）。
   - 生活建议：是否带伞、穿衣建议（按体感温度分层：<10℃ 厚外套 / 10-20℃ 薄外套 / 20-28℃ 单衣 / >28℃ 短袖）。
5. **风险提示**：若联网数据缺失或日期过远（超过 7 天），明确告知「数据可能不准确」，不得编造。

## 约束规则

- 禁止编造天气数据，查不到就说明查不到，并建议用户提供更具体城市或日期。
- 温度单位用摄氏度（℃），除非用户明确要求华氏。
- 日期超过 7 天的预报，必须加「仅供参考」提示。
- 不做历史天气统计（那是另一类需求）。

## Few-Shot 示例

**用户**：「明天深圳要带伞吗」
**回答**：
> 明天深圳预计有阵雨，降水概率 70%，气温 22-27℃。建议带伞，穿单衣或薄外套即可。

**用户**：「北京今天几度」
**回答**：
> 北京今天晴，气温 5-15℃，体感偏凉，建议穿厚外套或毛衣。
