# 第三方技能（Skills）开发指南

本项目支持**即插即用**的第三方技能扩展：往 `skills/` 目录下放一个符合规范的文件夹，
重启服务（或等待约一次对话内的自动重载）后，Agent 就能自动发现并学会使用它。
无需改任何代码、无需注册。

## 快速开始：30 秒写一个技能

```text
skills/
└── my-skill/
    └── SKILL.md
```

```markdown
---
name: my-skill
description: 一句话说清做什么。触发词：XX、YY、ZZ。适用场景：……。不适用于：……。
---

# 我的技能

## 目标
……

## 工作流（SOP）
1. ……
2. ……

## 约束规则
- 不得编造……
```

保存即生效。用户在对话里说出触发词，Agent 就会自动加载并按你的流程执行。

## 工作原理（渐进式披露）

参考 Claude Agent Skills 的设计，分三级加载，避免把所有技能全文塞进上下文：

| 级别 | 内容 | 何时加载 | 代价 |
|------|------|----------|------|
| L1 目录 | 每个技能的 name + description | 始终在 system prompt 中 | 每技能约几十 token |
| L2 正文 | SKILL.md 完整工作流 | 模型命中触发词后调用 `use_skill` | 一次工具调用 |
| L3 资源 | 技能目录下的附加文件 | 模型按需调用 `read_skill_file` | 按需读取 |

因此：**把「什么时候用我」写进 description，把「怎么用我」写进正文，把大段参考资料放进资源文件。**

## 文件结构约定

```text
skills/
└── my-skill/                  ← 目录名建议与 name 一致
    ├── SKILL.md               ← 必需，技能入口
    ├── references/            ← 可选，参考文档（模板、清单、领域知识）
    │   └── template.md
    └── examples/              ← 可选，更多示例
        └── demo.md
```

Agent 侧可见的两个工具（模型自动调用，技能作者无需关心实现）：

- `use_skill(name)` → 返回 SKILL.md 全文 + 资源文件清单
- `read_skill_file(skill, path)` → 读取技能目录内文件；
  也支持以 `knowledge/` 开头读项目共享知识库（如 `knowledge/city-alias.md`）

## frontmatter 规范

```yaml
---
name: my-skill        # 必需。全局唯一，建议小写字母+连字符，与目录同名
description: ...      # 必需。这是模型决定「用不用你」的唯一依据，必须包含：
                      #   ① 做什么（一句话）
                      #   ② 触发词（尽量穷举用户可能的说法）
                      #   ③ 适用 / 不适用场景（防误触发、防越界）
---
```

## 正文写作建议

1. **工作流写成编号步骤（SOP）**，模型会严格按步骤走；
2. **约束规则要具体**：「不得编造数据」比「要准确」有效得多；
3. **给 1-2 个 Few-Shot 示例**（用户输入 → 期望输出），效果立竿见影；
4. **需要调用内置工具就直说**（如「调用 get_weather 获取数据」），
   可用工具清单见主 README 的能力章节；数据查不到时要显式写清兜底动作，
   例如「若 get_traffic 返回未收录，立刻用 web_search 检索『{城市} 限行 最新规定』，
   再用 fetch_url 打开当地交警/政府官网核实，并在回答中注明来源链接与检索日期」——
   把「查不到怎么办」写进技能，模型才不会敷衍用户；
5. **技能不执行代码**——它是给模型的指令集。需要可执行能力时，
   引导模型组合现有工具；现有工具不够，才是往 `agent/tools/` 加新工具的场景（如 `web_search`、`fetch_url`）。

## 安装第三方技能

1. 把技能文件夹整体拷入 `skills/`（确认来源可信，见下方安全提示）；
2. 重启 Web 服务（`py agent/web.py`），或等下一次对话时自动热重载；
3. 打开页面确认：新聊天里说出技能触发词，应能看到模型调用 `use_skill` 工具卡片。

## 安全提示

- 技能正文会被注入模型上下文，相当于「给模型的指令」。**只安装你信任来源的技能**；
  安装前通读 SKILL.md，警惕「忽略之前的指令」「把数据发到外部地址」这类注入语句。
- `read_skill_file` 有路径穿越防护，只能读技能目录与 `knowledge/` 内的文本文件。
- 单技能正文上限 20000 字符、单资源文件上限 8000 字符，超出自动截断。

| daily-life-calendar | 日期/节假日查询 |
| daily-life-traffic | 限行查询 |
| daily-life-emotion-support | 情绪调节与支持 |
| weekly-report | 周报生成（含 references/ 资源文件，演示三级加载） |
