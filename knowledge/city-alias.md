# 城市别名与常用问题样例

## 城市别名归一化

| 别名 | 标准城市 |
| --- | --- |
| 帝都 / 京城 | 北京 |
| 魔都 | 上海 |
| 羊城 | 广州 |
| 鹏城 | 深圳 |
| 蓉城 | 成都 |
| 江城 | 武汉 |
| 山城 / 渝 | 重庆 |
| 春城 | 昆明 |

> 未列出的别名，优先按语境判断，不确定时向用户确认城市。

## 高频问题分类（用于检验召回）

- **天气类**：今天冷吗 / 明天要不要带伞 / 周末适合出门吗
- **日历类**：今天几号 / 下周三是几月几号 / 中秋节是星期几
- **限行类**：今天限几号 / 我车尾号 3 今天能开吗
- **反例（不应召回）**：帮我订机票 / 推荐旅游攻略（超出纯查询边界）

## 使用说明

本文件是三个 Skill 的共享知识，SKILL.md 中通过相对路径 `../knowledge/city-alias.md` 引用。新增城市别名时直接在本表追加一行。
